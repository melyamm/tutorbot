# Бот репетитора: модуль «Занятия / ДЗ»

## Что умеет

**Репетитор (ты)**
- Ученики: карточка, ставка за 60 мин, часовой пояс, архив.
- Подключение ученика и родителей одноразовыми ссылками.
- Регулярное расписание (слоты по дням недели) и разовые занятия, перенос, отмена.
- Напоминания ученику и родителю за день, ученику и тебе за час.
- После занятия бот сам ставит «проведено» и начисляет оплату. Если занятия не было, жмёшь «↩️ Не было».
- Через 30 минут после занятия родителю уходит счёт с кнопкой «Я оплатил(а)».
- Родитель присылает чек, тебе приходит заявка: подтвердить, поправить сумму или отклонить.
- ДЗ: текст, фото, альбомы, PDF. Срок, напоминания, просрочка, проверка с комментарием, доработка.
- Финансы: долги, доход за месяц, напоминание всем должникам одной кнопкой.
- Утренняя сводка: занятия на сегодня, что на проверке, кто должен.
- Бэкап базы в личку: `/backup` и автоматически каждое воскресенье.

**Ученик**: ближайшие занятия, «не смогу», домашка, сдача решений.

**Родитель**: расписание, «не получится», долг и подтверждение оплаты, статус домашек.

Ученик и родитель не отменяют занятия сами: по кнопке «не смогу» бот предлагает написать тебе, а тебе приходит уведомление с кнопками «🔁 Перенести» и «❌ Отменить».

## 1. Создай бота

1. В Telegram открой @BotFather, отправь `/newbot`, придумай имя и username.
2. Скопируй токен вида `123456789:AA...`.

## 2. Запуск на VPS (Ubuntu / Debian)

Нужен Python 3.10+.

```bash
ssh root@IP_СЕРВЕРА
apt update && apt install -y python3 python3-venv sqlite3 unzip
mkdir -p /opt && cd /opt
```

С Мака закинь архив на сервер (в другом окне терминала):

```bash
scp ~/Downloads/tutorbot.zip root@IP_СЕРВЕРА:/opt/
```

Дальше на сервере:

```bash
cd /opt && unzip tutorbot.zip && cd tutorbot
useradd -r -s /usr/sbin/nologin tutorbot || true
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
nano .env
```

В `.env` достаточно `BOT_TOKEN`. Запусти как сервис и сразу напиши боту `/start`: первый написавший становится репетитором (админом).


```bash
chown -R tutorbot:tutorbot /opt/tutorbot
cp deploy/tutorbot.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now tutorbot
journalctl -u tutorbot -f
```

Бот работает и сам поднимется после перезагрузки сервера.

**Важно:** один токен = один запущенный бот. Если запустишь его ещё и на Маке, будет ошибка `Conflict: terminated by other getUpdates request`. Тестируешь локально: останови сервис (`systemctl stop tutorbot`).

### Бэкапы базы

Каждое воскресенье после 21:00 бот сам присылает тебе файл базы в личку, вручную в любой момент: `/backup`. Восстановление: останови бота, положи файл на место `data/bot.db`, запусти.

Если бот на своём VPS, можно ещё и бэкапить на сервере.

Вся база в одном файле `data/bot.db`. Ежедневный бэкап с хранением 30 дней:

```bash
chmod +x deploy/backup.sh
(crontab -l 2>/dev/null; echo "30 4 * * * /opt/tutorbot/deploy/backup.sh") | crontab -
```

### Обновление кода

```bash
systemctl stop tutorbot
# заменить файлы в /opt/tutorbot, кроме .env и data/
.venv/bin/pip install -r requirements.txt
chown -R tutorbot:tutorbot /opt/tutorbot
systemctl start tutorbot
```

## 2б. Запуск на Bothost

В проекте уже есть `bothost.json` и `main.py`, переменные окружения не нужны.

1. Название: любое. Платформа: Telegram. Язык: Python 3.11.
2. Bot Token: токен от BotFather.
3. Git URL: ссылка на твой репозиторий, ветка `main`.
4. Создать бота. Сразу после запуска напиши боту `/start`: первый написавший становится репетитором (админом), больше никто им стать не сможет.
5. База лежит в `/app/data/bot.db`. Проверь, что она не стирается: добавь тестового ученика, перезапусти бота в панели, открой «👥 Ученики».

## 3. Первые шаги в боте

1. «➕ Новый ученик»: имя, класс, предмет, ставка.
2. В карточке «🕒 Расписание» → «➕ Добавить»: день, время, длительность.
3. «🔗 Ссылка ученику» и «🔗 Ссылка родителю»: бот пришлёт готовое сообщение, просто перешли его. Для второго родителя нажми ещё раз, ссылки одноразовые.
4. Если до бота были долги, в «📜 Операции» есть «➕ Начислить».
5. Посмотреть бота глазами ученика: создай ссылку ученику, перейди по ней сам, потом `/mode`. После теста `/unlink` и выдай ученику новую ссылку.

## Настройки `.env`

| Параметр | Что это | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен от BotFather | |
| `ADMIN_IDS` | необязательно: Telegram ID репетиторов через запятую. Без него админом становится первый, кто написал `/start` | |
| `TUTOR_TZ` | твой часовой пояс | `Europe/Moscow` |
| `DIGEST_HOUR` | во сколько утренняя сводка | `9` |
| `BILL_DELAY_MIN` | через сколько минут после занятия родителю уходит счёт | `30` |

## Ограничения MVP

- Если бот перезапустится, пока ты что-то вводишь (например, собираешь ДЗ), ввод сбросится. Данные в базе не теряются.
- Переносит и отменяет занятия только репетитор.
- Онлайн-оплаты картой нет, только ручное подтверждение перевода.
- Ставка в рублях за 60 минут, стоимость считается пропорционально длительности (90 мин при 1500 ₽ = 2250 ₽).
